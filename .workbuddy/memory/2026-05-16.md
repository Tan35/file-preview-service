## 修复浏览器端上传 "Invalid key" 根因
- **根因定位**：浏览器 `fetch` 会自动 URL-encode 非ASCII字符（如中文文件名），导致路径中出现 `%` 字符，而 S3 对象键禁止 `%`。
- **修复方案**：上传路径改用 `crypto.randomUUID() + 扩展名`（如 `uploads/a1b2c3d4.docx`），原始文件名存入 Supabase metadata。
- **修改文件**：
  - `src/components/FileUpload.tsx`：移除 `diagnoseSupabase` 调用，改用 UUID 路径
  - `src/lib/supabase.ts`：移除 `diagnoseSupabase` 诊断函数（约120行）
- **验证**：TypeScript 编译无新增错误，开发服务器正常启动在 `http://localhost:5174/`
